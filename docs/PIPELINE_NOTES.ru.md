# СИЛАНТ — анализ и прогноз рынка вилочных погрузчиков РФ

## Обновление одной командой
```bash
pip install -r requirements.txt
python update.py --xlsx путь/к/новому_файлу.xlsx     # новый квартал = новый столбец справа, формат как у заказчика
```
Что происходит:
1. **Проверка файла**: все кварталы подряд, нет пустых и отрицательных, сумма сегментов = «Итого», состав сегментов тот же,
   пересмотры истории, подозрительные скачки нового квартала (×3 к тому же кварталу год назад). Ошибка → остановка (обойти: `--force`).
2. Новый файл кладётся в `data/raw/`, прежний — в `data/raw/archive/` (папка создаётся при первом обновлении с `--xlsx`).
3. (опционально `--fetch`) обновление рядов Банка России; проверка, хватает ли факторов и сценарных допущений на новый горизонт —
   недостающее достраивается базовым сценарием / последним значением **с предупреждением**.
4. Пересчёт 6 ноутбуков (данные → тренды/сезонность → факторы → модели и прогноз на 4 кв. → сценарии → 8 кв.), HTML-версии в `reports/`.
5. **`reports/summary.html`** — сводка с актуальными цифрами, проверками, изменением к прошлому запуску, проверкой прошлого прогноза на новом факте
   и решающим правилом по ДВС (по факту II и III кв. 2026 г.: спад / восстановление / ждать);
   **`reports/silant_forecast.xlsx`** — все ключевые таблицы.
6. Архив запуска `data/runs/<квартал>__<время>/` (для сравнения со следующим запуском).

Другие режимы: `python update.py` (пересчёт на текущем файле), `--check` (только проверка), `--fetch` (обновить ЦБ).
Тест без реальных данных: `python tests/make_test_quarter.py` создаёт **синтетический** следующий квартал (запускайте в копии проекта).
Автотесты ядра (≈5 с): `python -m pytest -q tests` — чтение файла, проверки качества (отрицательные/пустые значения останавливают обновление),
иерархия рядов, согласованность каждой траектории прогноза, воспроизводимость при фиксированном seed,
правило уровня плана, решающее правило по ДВС, продление инфляции после горизонта прогноза ЦБ.
Обновление проверено на синтетических кварталах: II кв. 2026 — I кв. 2027 добавлялись по одному подряд, пересчёт проходит.
Точные версии библиотек, на которых результаты проверены в чистом окружении: `requirements-lock.txt` (`pip install -r requirements-lock.txt`).

**Как менять ноутбуки.** Ноутбуки `notebooks/0X_*.ipynb` генерируются из `notebooks/build_0X.py` при каждом запуске `update.py`:
правки, сделанные прямо в .ipynb, будут перезаписаны. Код и текст меняются в `build_0X.py`.

Что обновлять вручную раз в квартал: `data/external/manual/rosstat_via_media.csv` (инвестиции, промпроизводство — Росстат),
`data/external/manual/scenarios.csv` (допущения сценариев на новый горизонт), `macro_forecasts.csv` (новые прогнозы ЦБ/Минэка).
Текст выводов в ноутбуках написан по данным до 2026Q1 — при новых данных в ноутбуках появляется предупреждение, актуальные цифры — в summary.html.


## Структура
```
data/raw/            исходный Excel заказчика (не редактируется)
data/processed/      market_long.csv — long-формат (type, segment, capacity_class, quarter, units)
                     quality_totals.csv, quality_segments.csv, quality_anomalies.csv — проверки
src/silant_data.py   загрузка, long-формат, проверки, поиск аномалий
src/silant_ts.py     тренд, слом, сезонность, бэктест
src/silant_macro.py  сборка квартальных внешних рядов с источниками
src/fetch_external.py обновление рядов Банка России (нужен доступ к cbr.ru)
src/silant_forecast.py модели (Наивный, Сезонный наивный, ETS, ARX-ставка, Комбинация), rolling-origin, согласование, интервалы
data/external/       raw/ (ЦБ), manual/ (Росстат через СМИ, прогнозы, контекст), SOURCES.md
notebooks/           01_data_eda, 02_trend_seasonality, 03_external_factors, 04_forecast, 05_scenarios, 06_long_horizon (собираются из build_0X.py)
reports/             01_data_eda.html, figures/*.png
```


Новый квартал = новый столбец справа в Excel. Парсер ищет блоки по заголовкам
(«Объем рынка Автопогрузчиков/Электропогрузчиков») и кварталы по шапке «N кв.YYYY»,
поэтому код менять не нужно.

## Long-формат `market_long.csv`
| поле | описание |
|---|---|
| type | ДВС / Электро |
| segment | сегмент грузоподъёмности как в файле (нормализованная подпись) |
| cap_min, cap_max | границы сегмента, т |
| capacity_class | гармонизированный класс для сравнения ДВС и электро (6 классов) |
| power | мощность из файла (справочно) |
| quarter, date, year, q | квартал (2023Q1), конец квартала, год, номер квартала |
| units | продажи, шт. |

## Прогноз (этап 04)
`data/processed/forecast_4q.csv` — поквартальный прогноз всех узлов иерархии (mean, квантили 2,5/10/50/90/97,5%),
`forecast_4q_total.csv` — сумма за 4 квартала, `forecast_4q_e_share*.csv` — доля электро, `backtest_rolling_origin.csv` — валидация.
Горизонт сдвигается автоматически: 4 квартала после последнего квартала в Excel.

## Сценарии (этап 05)
Допущения — `data/external/manual/scenarios.csv` (ставка, инвестиции, доля передачи снижения ставки в спрос; у каждой строки обоснование).
Выход: `scenario_forecast_totals.csv` (суммы за 2 × 4 квартала, квантили), `scenario_forecast_q_{base,conservative,optimistic}.csv`, `scenario_e_share.csv`, `scenario_components.csv`.

## Долгосрочный прогноз (этап 06)
8 кварталов × 3 сценария × 4 слоя неопределённости (L1 статистический, L2 горизонт, L3 факторы, L4 структурный).
Выход: `long_forecast_quarterly_layers.csv`, `long_forecast_totals_layers.csv`, `long_forecast_table_L3.csv`, `long_forecast_e_share.csv`.

## Дополнительно: программа с окном
